Upload an image

Pick a file, press upload, get a link back. That's the whole thing.

  1. Upload it. Send the actual image to a Supabase bucket. The page must get the file from an input element with type="file". The accept attribute tells the browser to offer images — it's a helpful hint, not a security check. 
    <input type="file" id="file" accept="image/*" />
  2. Remember it. Save the path in a database table.
  3. Show it. Turn that path into a URL and put it in an <img>.

What Supabase needs first

Two things, set up once. Paste each one into the SQL Editor and press Run.

  1. A policy that lets visitors upload. Supabase blocks everything by default — that's a safety feature, not a bug. A policy is the guest list. This one says "anonymous visitors may add files to this bucket". 
    create policy "anyone can upload"
on storage.objects for insert to anon
with check (bucket_id = 'app_assets');
  2. The table that remembers the paths. The bucket holds the pictures. This table holds the paths — where each picture can be found. It needs its own two policies for the same reason as above. 
    create table if not exists images (
  id   bigint generated by default as identity primary key,
  path text not null
);

alter table images enable row level security;

create policy "anyone can add rows"
on images for insert to anon with check (true);

create policy "anyone can read rows"
on images for select to anon using (true);

If you get "policy already exists", you've run it before. That's fine — skip that one.
